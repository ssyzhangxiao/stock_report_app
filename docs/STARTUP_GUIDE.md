# 🚀 启动脚本使用说明

## ✨ 新功能：自动打开浏览器

`start.sh` 脚本现已支持**自动打开浏览器**功能！

---

## 📋 使用方法

### 一键启动（推荐）

```bash
./start.sh
```

脚本会自动执行以下步骤：

1. ✅ 安装后端依赖（如未安装）
2. ✅ 启动后端服务（端口 9000）
3. ✅ 安装前端依赖（如未安装）
4. ✅ 启动前端服务（端口 6000）
5. ✅ **自动打开浏览器访问 http://localhost:6000** 🎉

---

## 🌐 浏览器兼容性

脚本支持以下操作系统：

| 操作系统 | 命令 | 状态 |
|---------|------|------|
| **macOS** | `open` | ✅ 支持 |
| **Linux** | `xdg-open` | ✅ 支持 |
| **Windows** | `start` | ✅ 支持 |

如果您的系统不支持自动打开，脚本会提示您手动访问。

## 🔧 自定义配置

### 修改默认浏览器

#### macOS

```bash
# 设置默认浏览器为 Chrome
export BROWSER=open
./start.sh

# 或使用特定浏览器
open -a "Google Chrome" http://localhost:6000
```

#### Linux

```bash
# 设置默认浏览器
export BROWSER=firefox
./start.sh
```

#### Windows

```cmd
:: 设置默认浏览器
set BROWSER=chrome
start.sh
```

### 禁用自动打开浏览器

如果您不想自动打开浏览器，可以：

**方法一**：注释掉相关代码

编辑 `start.sh`，找到以下部分并注释：

```bash
# 自动打开浏览器
# echo "🌐 正在打开浏览器..."
# if command -v open &> /dev/null; then
#     open http://localhost:6000
# elif ...
```

**方法二**：手动启动

不使用 `start.sh`，而是分别启动：

```bash
# 终端1 - 后端
cd backend
source venv/bin/activate
uvicorn app.main:app --reload --port 9000

# 终端2 - 前端
cd frontend
npm run dev
```

然后手动在浏览器中访问 http://localhost:6000

## ⚠️ 注意事项

### 1. 等待时间

脚本会等待 **3 秒**让前端服务完全启动后再打开浏览器。

如果网络较慢或电脑性能较低，可以增加等待时间：

```bash
# 修改 start.sh 中的 sleep 时间
sleep 5  # 改为 5 秒
```

### 2. 浏览器未打开

如果浏览器没有自动打开：

1. 检查系统是否支持 `open`/`xdg-open`/`start` 命令
2. 检查默认浏览器设置
3. 手动访问 http://localhost:6000

### 3. 端口冲突

如果端口被占用，脚本会失败。请先关闭占用端口的进程：

```bash
# macOS/Linux
lsof -i :6000
kill -9 <PID>

lsof -i :9000
kill -9 <PID>
```

## 📝 故障排除

### Q1: 脚本无法执行

**错误**：`Permission denied`

**解决**：
```bash
chmod +x start.sh
./start.sh
```

### Q2: 浏览器打开但页面空白

**原因**：前端服务尚未完全启动

**解决**：
- 等待几秒后刷新页面
- 或增加脚本中的 `sleep` 时间

### Q3: 显示 "Network Error"

**原因**：后端服务未启动或端口不匹配

**解决**：
1. 检查后端是否正常启动
2. 检查 `vite.config.ts` 中的代理配置
3. 重启服务

### Q4: 自动打开的浏览器不是默认的

**原因**：系统默认浏览器设置问题

**解决**：
- macOS: 系统偏好设置 → 通用 → 默认网页浏览器
- Linux: 系统设置 → 默认应用
- Windows: 设置 → 应用 → 默认应用

## 💡 小技巧

### 1. 后台运行

```bash
# 在后台运行，不占用终端
nohup ./start.sh > startup.log 2>&1 &
```

### 2. 查看日志

```bash
# 实时查看启动日志
tail -f startup.log
```

### 3. 快捷别名

在 `~/.zshrc` 或 `~/.bashrc` 中添加：

```bash
alias stock-start='./start.sh'
```

然后只需运行：

```bash
stock-start
```
