## 一、整体布局

```
2列 Grid (2fr 1fr) + 底部通栏
├── 左列（数据区）
│   ├── K线走势
│   └── 财务数据分析（3个Tab）
├── 右列（分析区）
│   ├── 财务速览 + 质押进度
│   ├── 上市公司概况

│   ├── 控制权资金分析
│   ├── 分析师评级
│   ├── 新闻舆情

└── 底部通栏

```

## 二、各组件的展示内容

### 1. 顶部标题栏
```
📊 控制权转让 · 基本面看板
[代码输入框] [分析] [导出] [全屏]
```

### 2. 核心数据条

- 转让进度 Tag
- 潜在买家名称 + 背景描述
- 控制权溢价率（传闻价vs现价）
- 近期事件时间线

## 三、配色方案

```
背景:    #f5f7fa
卡片:    #fff
边框:    #e8ecf1
阴影:    0 1px 4px rgba(0,0,0,0.05)

涨:      #ff4d4f
跌:      #52c41a
警告:    #faad14
主色:    #1890ff

PE对比:
  > 行业×2:  红色背景 + 红字
  > 行业×1.3: 黄色背景 + 橙字
  ≈ 行业:    绿色背景 + 绿字

标签颜色:
  低风险:  green / #52c41a
  中风险:  orange / #faad14
  高风险:  red / #ff4d4f
```

## 四、已知问题

1. K线图在2/3列宽度下，日期标签偶尔重叠（ECharts自动压缩）
2. 财务速览中若某期数据为空，环比显示 "--"
3. 控制权状态数据依赖AI生成，首次需点击按钮
4. 风险事件监控仅显示 sentiment=negative 的新闻，可能遗漏
5. 全屏模式需浏览器 API 支持（iOS Safari 不支持）
